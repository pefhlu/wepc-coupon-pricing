## 退款、换 IP 和付款

退款按时间和流量双条件判定：

- 3 天内且用量不超过 10GB：可全额退到账户余额，或每台扣 10 元手续费后原路退回
- 3 到 10 天内：不能原路退回，按每天扣 6% 的比例把剩余部分退到余额
- 超过 10 天：不再支持退款
- 余额不可提现，用余额支付的订单只能退回余额
- 同一笔交易不能二次退款，同一天不超过 3 笔，每月不超过 5 笔
- 标注“不支持退款”的产品除外，比如香港 `HK_Lite_1522T`

这里的 10GB 是流量上限，不是时长之外的附加条件。直播推流测试消耗很快，一小时高清推流就可能吃掉好几个 GB，把测试压在这个窗口里做，别开着推流放一整天再申请退款。
